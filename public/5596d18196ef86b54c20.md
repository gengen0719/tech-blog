どうも勉強会、カンファレンス参加大好きおじさんです。
予定の整理をしていたところ、気づいたら色々なイベントに参加する予定だったので、今年前半に参加予定の大きめのイベントを列挙してみます。
各イベント参加される方はぜひ現地で僕と握手！

# 大きなイベントは初心者の方にもおすすめ
- 色々なセッションが同時並行で開催されるので興味のあるセッションがきっと見つかる
- 盛り上がっていて楽しい
- 聞くだけでも全然OKで気楽に参加できる

# JAWS DAYS 2026 3/7（土）

https://jawsdays2026.jaws-ug.jp/

JAWS-UG（AWS User Group – Japan）主催のイベントです。
去年も気になっていたのですが、参加できずで今年初参加の予定です。
8トラック並行でお祭り班やJamなど色々なセッションが行われます。

JAWS-UGは全国に60以上の支部があり、私も大阪や京都など関西の支部のイベントにはよく参加させていただいています。
関西の支部の知り合いの方もたくさん参加されたり登壇されたりしますし、全国からAWSに熱い思いを持った方々がたくさん集まるようなので、とても楽しみです。


# クラウドネイティブ会議 5/14（木） 5/15（金）

https://kaigi.cloudnativedays.jp/

前々からPlatform Engineering Kaigiが気になっていたのですが、今年はCloudNative Days、SRE Kaigiと合同開催、さらに名古屋で奈良県民としてはとても行きやすい、ということもあり参加申し込みをしました。タイムテーブルはまだ出ていませんが、個人的にもっと勉強していかないといけないなという領域で楽しみです。

# JJUG CCC Spring 5/30（土）

https://x.com/JJUG/status/2015651225145086134

> JJUG CCCは日本最大のJavaコミュニティイベントです。Java関連の技術や事例に関する良質なセッションが行われ、また異なる分野で活躍するJava技術者が一堂に会する場ともなっています。

春と秋に年２回行われる国内最大のJavaコミュニティのイベントです
今回はプロポーザルの募集が今日までなので、まだタイムテーブルは出ていませんが、前回は8セッション並行で行われました。おそらく今回も同規模で開催されるものと思います。

https://jjug.doorkeeper.jp/events/190868

前回のタイムテーブル

AWS Japanが主催する日本最大のAWSを学ぶイベント。
今年のイベントページはまだですが、去年のページに今年の開催日程が発表されています。

https://aws.amazon.com/jp/summits/japan/?trk=f950cb6d-36c6-4759-bc31-fccf2b92dcc3&sc_channel=el?utm_source=vendelux.com

（160以上のセッション、270以上の展示が行われていたようです）

昨年のタイムテーブル、会場マップ
https://pages.awscloud.com/rs/112-TZM-766/images/AWS%2BSummit%2B2025_SessionGuide.pdf

今年もがっつり楽しみます。
会場周辺のホテルはSummit効果で満室になってしまうため、遠方から参加される方は早めのご予約をおすすめします。

# きのこカンファレンス2026 6/28（日）

https://kinoko-conf.dev/index.html

> 「エンジニアがこの先生きのこるためのカンファレンス」は、参加される方がそれぞれのキャリアやロードマップを見つめ直し、自身の未来を描くヒントを得ることを目的に開催するITカンファレンスです。
登壇者を40歳以上のベテランエンジニアに限定して、エンジニアとして長い時間を歩んできた彼らから経験や知識を吸収することで、参加者が末永くエンジニアを続けられることを目指します。
現役ITエンジニアをはじめ、デザイナーやマネージャーなど周辺職に就かれている方、ITエンジニアを目指す学生など、幅広い方にご参加いただけます。

登壇者が40歳以上のベテランエンジニア限定という面白いコンセプトのカンファレンスです。
昨年とても気になりつつ都合が合わなかったのですが、今年も開催されるということで参加したいと思っています。昨年のXでもたくさんの学びがあったという声をみたため、楽しみです。

昨年のタイムテーブルはこちら

https://fortee.jp/kinoko-2025/timetable/2025-03-09

# おわりに
私はもともとエンジニアという仕事がとても好きで天職だと思っていましたが、数年前まであまり勉強会やカンファレンスには参加してきませんでした。
勉強会やカンファレンスへの参加を始めて、「エンジニア人生で今が一番楽しい」を更新し続けられているなと感じています。
まだエンジニアイベントに参加したことがないという方は、気楽な気持ちで参加してみるとエンジニアライフがより楽しくなるかもしれません。

おわり。
